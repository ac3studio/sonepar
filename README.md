# sonepar

Created with Encore.

## Kiosk experience

The interface is designed exclusively for a 1920×1080 landscape touchscreen. The fixed landscape canvas scales uniformly to fit other displays; mobile and narrow-screen reflow are not supported. After 3½ minutes without interaction, it shows a 30-second warning before returning to the start. Touch or keyboard activity keeps the current view open.

Roboto is bundled locally in `static/fonts` for offline use; its license is included there. Chapter photos and partner logos are original source media documented in `static/images/SOURCES.md`, not flattened card composites.

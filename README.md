# sonepar

Created with Encore.

## Kiosk experience

The interface is designed for a 1920×1080 landscape touchscreen and reflows into a scrollable layout at narrower viewports. After 3½ minutes without interaction, it shows a 30-second warning before returning to the start. Touch or keyboard activity keeps the current view open.

Roboto is bundled locally in `static/fonts` for offline use; its license is included there. Chapter photos and partner logos are original source media documented in `static/images/SOURCES.md`, not flattened card composites.
